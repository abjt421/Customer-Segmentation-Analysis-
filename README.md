# Customer-Segmentation-Analysis
Customer Segmentation Analysis: A Comparative Study of K-Means and Hierarchical Clustering

## Overview
This project analyzes a dataset of over 3.5 lakh customer transactions to segment customers based on their purchase behavior, demographics, and transaction frequency. The primary objective is to enable targeted marketing by identifying distinct customer groups using unsupervised machine learning techniques.

## Objectives
- Understand customer behavior through data-driven segmentation.
- Compare the effectiveness of K-Means and Hierarchical Clustering.
- Recommend the optimal approach based on clustering performance metrics.

## Methodology
- **Data Preprocessing**: Cleaning, feature engineering, and normalization.
- **Exploratory Data Analysis**: Visualization of spending patterns, demographics, and correlations.
- **Clustering Algorithms**:
  - **K-Means Clustering**
  - **Hierarchical Clustering (Agglomerative)**
- **Evaluation Metrics**:
  - **Silhouette Score**
  - **Davies-Bouldin Index**

## Results
- **K-Means Clustering** outperformed Hierarchical Clustering:
  - Silhouette Score: **0.714**
  - Davies-Bouldin Index: **0.706**
- 3 distinct clusters were identified with clear behavioral patterns.
